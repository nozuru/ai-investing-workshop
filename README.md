# 投資にAIをどう使うか：勉強会の作業フォルダ

講師の話を参考に、自分たちの投資戦略を考えて言葉にし、AIに実装させて、過去の価格データで確かめる3時間の勉強会です。
講師の話はあくまで考える材料なので、どんな戦略にするかは自分たちで決めます。普段から使っている自分の戦略がある人は、それを持ち込んでも構いません。
言葉にできない戦略は、AIにも実装できず、検証も振り返りもできません。
儲かる戦略を当てることよりも、「何に賭けていて、どんなときに負けるか」を説明できるようになることを目指します。

最後に、講師が「設計として一番良かったチーム」を選びます。評価のポイントは次の4点です。

- 仮説と根拠がはっきり書けているか
- どんな相場で勝ち、どんな相場で負けるかが書けているか
- 実装が設計書どおりになっているか
- AIに任せる部分と人が決める部分の線引きに、納得できる理由があるか

バックテストの成績順位も発表しますが、こちらは余興です。数か月の成績はほぼ運で決まります。

## 用意するもの

チームで1台、コーディングAI（Claude Code、Codex、Cursorなど）が動くPCがあれば十分です。
Pythonの環境は、AIが `uv` を使って作ります。`uv` が入っていなければ、AIに「uvを入れて」と頼んでください。

## 進め方

### 1. このフォルダを取得してAIを起動する

作業したい場所でコーディングAIを起動し、次のように頼みます。GitHubのアカウントは要りません。

```
https://github.com/nozuru/ai-investing-workshop を取ってきて。gitがなければZIPで落として展開して。フォルダ名は ai-investing-workshop にして。
```

取得できたら、**いったんAIを終了し、`ai-investing-workshop` フォルダの中で起動し直してください。**
AIは起動したフォルダにある [AGENTS.md](AGENTS.md) のルールに従って動きます。フォルダの外で起動したまま続けると、このルールが読み込まれません。

gitが使える人は、自分で取得しても構いません。

```sh
git clone https://github.com/nozuru/ai-investing-workshop
cd ai-investing-workshop
```

### 2. 壁打ちして設計書を書く（35分）

AIに次のように伝えます。

```
壁打ちしたい。私たちの投資アイデアは「……」です。
```

AIが質問をまとめて出すので、チームで相談して答えます。答えに迷ったら、質問に添えられた例を参考にしてください。
決まったことはその都度、設計書 `STRATEGY.md` に書き足されていきます。

コーディングAIを使えない人は、[skills/grill-investing/SKILL.md](skills/grill-investing/SKILL.md) の中身をチャットAIに貼り付ければ、同じ壁打ちができます。

### 3. 実装して検証する（40分）

```
STRATEGY.md を実装して、バックテストして。
```

結果は `results.md` とグラフ画像 `equity.png` に出力されます。
結果を見て戦略を変えたくなったら、先に `STRATEGY.md` を書き直してから、AIに実装を修正してもらいます。
成績が良すぎるときは、まず誤りを疑ってください。AIに「このバックテストに未来の情報を使っている箇所がないか点検して」と確認を頼むこともできます。

LLMやニュースを戦略に使いたいチームは [docs/llm-and-news.md](docs/llm-and-news.md) を読んでください。

### 4. 最終実行（5分）

進行役の合図で、それまで検証に使っていなかった2026年7月以降の期間で、1回だけ実行します。

```
最終実行して。
```

### 5. 発表（3分）

`STRATEGY.md` と `results.md` を画面に映して発表します。
発表で話す内容は次の4点です。

- 戦略の一言説明
- 取っているリスク
- AIに任せた部分と、人が決めた部分
- 開発期間と最終実行の結果の差
